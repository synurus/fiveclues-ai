## 2. 꼭 챙길 것

### 오늘의 문제가 끊기지 않게
- 오늘의 문제 일정(`scripts/daily/ko.json`, `en.json`)은 **Pregenerate Hint Sets가 돌 때만** 채워진다.
  며칠 안 돌면 "아직 준비되지 않았어요"가 뜬다.
- 확인: 저장소에서 `scripts/daily/ko.json`을 열어 마지막 날짜가 오늘보다 며칠 뒤인지 본다.
- 안 돌았으면 **수동 실행**: Actions → **Pregenerate Hint Sets** → 오른쪽 **Run workflow** →
  (호출 수는 기본 8 그대로) → Run workflow. 10분 안팎 걸리고, 끝나면 봇이 직접 커밋한다.
- 제미나이가 과부하(503)면 자동으로 대체 모델로 만든다. 하루 한도를 넘기지 않게 스스로 멈추니
  여러 번 눌러도 된다(다만 같은 날엔 한도가 금방 찬다).

### 오늘의 문제 검토 이슈(라벨 `daily-review`)
일정에 새 날짜가 들어가면 이슈가 하나 열린다. 날짜마다 정답·묘사·동의어 후보가 표로 있다.
- **동의어 반영**: 맞다고 봐야 할 답(예: "마라탕"에 "마라 탕")이 있으면 `scripts/words.json`에서 그
  제시어의 `accept` 배열에 추가한다. ⚠️ 다른 제시어와 겹치는 말은 넣지 않는다(표에 경고가 뜬다).
- **묘사가 이상하면**: `scripts/daily/ko.json`(또는 `en.json`)에서 그 날짜 항목을 통째로 지운다.
  다음 Pregenerate 실행 때 다시 채운다. 이미 지난 날짜나 오늘 날짜는 지우지 않는다.
- 다 봤으면 이슈를 닫는다. 이슈 본문엔 정답이 있다(공개 저장소).
- GitHub 웹에서 파일 옆 연필 아이콘으로 바로 고치고 커밋해도 된다.

### 자가개선 PR(제목 "자가개선: 출제자 프롬프트 문구 조정 …", 브랜치 `self-improve/…`)
- 열리면 **사람이 판단해서 병합**한다. 이상하면 그냥 닫으면 된다 — 다음 실행 때 새 PR이 온다.
- 볼 것: PR 본문의 "왜 바꿨는지", 본문 글자 수 변화(10% 넘게 늘면 애초에 안 열림), 최근 3세대 성적 표.
- 성적 표는 표본이 작다 — 신뢰구간이 겹치면 "나아졌다"고 보지 않는다.
- 열린 PR을 오래 두면 다음 PR이 안 열리고 피드백만 쌓인다. 며칠 안에 병합하거나 닫는다.
- 병합하면 "세대"가 바뀐다 → 미리 만든 세트가 새 세대로 다 바뀌는 데 약 10일, 다음 PR까지 다시 30판.
- 영어판 지시문(`hintPromptEn.ts`)은 자동으로 안 따라간다. 한국어판에 의미 있는 변화가 쌓이면
  직접 맞출지 판단한다.

### 토큰·키 만료
| 이름 | 어디에 | 쓰임 | 만료되면 |
|---|---|---|---|
| `GITHUB_FEEDBACK_TOKEN` | Vercel 환경변수 | 플레이어 피드백 → 공개 이슈 | 피드백 전송 실패 — GitHub에서 재발급(이슈 쓰기 권한) 후 Vercel 값 교체·재배포 |
| `GITHUB_ACTIONS_TOKEN` | 이 PC `apps/backend/.env` | 로컬에서 워크플로 실행 요청 | 로컬 전용 — Actions 화면 버튼으로 대신해도 됨 |
| `SELFIMPROVE_BOT_API_KEY`·`GEMINI_API_KEY` | GitHub Secrets, Vercel | 제미나이(출제·세트 생성·자가개선) | 키가 없으면 제미나이가 빠지고 Groq만으로 출제 |
| `BOT_API_KEY` | GitHub Secrets, Vercel | Groq(출제 대체·자동플레이) | Groq 콘솔에서 재발급 후 두 곳 교체 |
| `GAME_TOKEN_SECRET` | Vercel | 게임 세션 암호화 | 바꾸면 진행 중인 판만 끊긴다 |

GitHub 토큰 만료일: GitHub → Settings → Developer settings → Fine-grained tokens에서 본다.

## 3. 뭔가 이상할 때

| 증상 | 먼저 볼 곳 |
|---|---|
| "아직 준비되지 않았어요"(오늘의 문제) | `scripts/daily/*.json`에 오늘 날짜가 있나 → 없으면 Pregenerate 수동 실행 |
| 게임 시작이 계속 실패 | Vercel → 프로젝트 → Logs. 429면 무료 한도 소진(Groq는 하루 토큰 한도, 몇 시간 뒤 풀림), 503이면 과부하 |
| 피드백이 이슈로 안 올라옴 | `GITHUB_FEEDBACK_TOKEN` 만료 여부(Vercel Logs에 401/403) |
| 워크플로가 빨간색(실패) | 그 실행을 눌러 로그 확인. 한두 번은 일시 오류일 수 있다 — Re-run jobs |
| 예약 실행이 하루 종일 안 돔 | GitHub 지연 — 필요한 것만 Run workflow로 수동 실행 |

제미나이 무료 한도는 모델별 하루 20회 수준이고 태평양 시간 자정(한국 16~17시)에 초기화된다.

## 4. 로컬에서 할 때(선택)

```bash
npm install
npm run dev                  # 로컬 실행 — API는 API_PORT(기본 3000), 화면은 5173
npm test -w backend          # 테스트
npm run metrics              # 세대별 성적(정답률)
npm run pregen -w backend    # 묘사 세트 생성(로컬) — 끝나면 scripts/hintsets·daily를 직접 커밋
```

- 환경변수는 `apps/backend/.env`(깃에 안 올라감). 새 환경변수를 코드에서 읽을 땐 `??`가 아니라 `||`.
- 로컬 실험도 운영과 같은 키를 쓴다 — 많이 돌리면 실제 게임 한도를 먹는다.

## 5. 가끔 볼 것
- **Search Console**: 색인 제외 페이지, 사이트맵(`/sitemap.xml`) 상태.
- **애드센스**: 심사 결과. 콘텐츠 페이지는 정적 HTML(`apps/frontend/*.html`, `guides/`, `en/`) —
  페이지를 추가하면 `vite.config.ts`의 `CONTENT_PAGES`와 `public/sitemap.xml`도 같이 고친다.
- **데이터 흐름을 바꾸면**(무엇을 어디로 보내는지) `privacy.html`·`en/privacy.html`을 같이 고친다.
- **운영자 실명은 어디에도 쓰지 않는다**(표기는 흑기사 Black_Knight).
