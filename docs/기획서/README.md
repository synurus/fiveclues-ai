# 기획서 버전 관리

Zeteo 기획서는 Claude Artifact로 작성됩니다. 이 폴더는 저장소에 파일로 두는 대신, 버전별 Artifact 링크만 기록합니다.

폴더 구조·기술 스택 등 기획이 크게 바뀌면 새 버전을 올리고, 이전 버전 링크는 지우지 말고 표에 그대로 남겨둡니다.

### 판이 바뀔 때마다 무엇이 달라졌나

각 판의 §1이 이전 판과의 차이를 표로 정리하고 있어, **최신 판 하나만 읽어도 완결됩니다.** 이전 판을 거슬러 읽을 필요는 없습니다.

- **v1.0 → v2.0** — 선언문에서 실측으로. 만들어보고 알게 된 것을 담았습니다
- **v2.0 → v3.0** — 5판을 실제로 플레이하고 알게 된 것. *"봇이 사람처럼 보이는 일은 프롬프트가 아니라 구조의 문제"* 가 이 판의 결론입니다
- **v3.0 → v4.0** — 문서의 역할 자체가 바뀌었습니다. v3.0은 설계까지 확정했고, v4.0은 **방향만 확정**하고 설계는 각자에게 넘깁니다
